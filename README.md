
# Matthias Bradshaw | Computer Science ePortfolio

**Southern New Hampshire University — CS-499 Computer Science Capstone**
---

Welcome to my computer science ePortfolio. This portfolio documents my growth throughout SNHU's Bachelor of Science in Computer Science program, culminating in my transformation of an introductory Java rescue-animal terminal application from one of my first courses into a full-stack Animal Rescue Management System using all of the knowledge I have gained. It includes my professional self-assessment, initial code review, original artifact, and enhancement through the three categories of software design and engineering, algorithms and data structures, and databases.
